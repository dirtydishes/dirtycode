# Program architecture research

The full report is [From idea to shipped Program](./idea-to-shipped-program-architecture.html).

It studies how Dirtycode can turn a goal into a durable Program with accepted revisions, typed work
graphs, bounded attempts, exact evidence, recovery, and visible state. It also defines the intended
split between Dirtycode/T3, dirtyloops, and Beads.

This report is research input. It does not accept an implementation revision, choose an integration
base, authorize product work, or decide which existing Program code to keep.
